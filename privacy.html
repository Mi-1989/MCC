Privacy policy

Effective date: 31 October 2026

This policy describes how MCC ("the tool") handles data. The tool is a private, single-user application that runs on its owner's own computer.

Google data the tool accesses

With the owner's permission, the tool uses the YouTube Data API to access the owner's own YouTube account. It uses this access only to:

  • upload the owner's videos, thumbnails and captions;
  • set titles, descriptions and visibility on the owner's videos;
  • read back the owner's own video and caption details to confirm changes.

How data is stored

The sign-in token and upload records are stored only on the owner's computer. The tool has no server and does not send data anywhere except to Google's YouTube API.

Sharing

The tool does not sell, share or transfer Google user data to any third party. It does not use Google user data for advertising, and it does not collect data about anyone other than the owner.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube data is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Removing access

The owner can revoke the tool's access at any time at Google Account permissions. Revoking access stops all further API use. Local records can be deleted from the owner's computer.

Contact

Questions about this policy can be raised through this site's GitHub repository.
